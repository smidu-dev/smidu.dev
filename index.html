How it works

You decide what gets built. The machine does the rest.

01

Describe

Write the idea in plain words. The planner says what it understood and asks before it plans.

02

Plan

Milestones in order, each saying what you can do when it is done. Stories for one milestone at a time.

03

Approve

One decision approves a milestone. Nothing is built that you did not say yes to.

04

Build

A developer writes it in a sandbox, a reviewer that cannot write checks it, CI tests it, then it merges.

Built by itself

Smidu is built by Smidu.

Its own queue, self-update and installer were planned as stories and built by its own Supervisor: fourteen stories in one evening, each one developed, reviewed, tested and merged without a human touching the code.

A working MVP.
Honestly.

Smidu runs privately on one machine for one owner. It is not a service you can sign up for — yet. This page shows what it does today.

Works today

  • Idea to milestones to stories
  • Build, independent review, CI, merge
  • Several apps from one queue
  • Updates and installs itself

Not yet

  • Accounts for other people
  • Public hosting
  • A week without an operator

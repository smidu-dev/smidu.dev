How it works

You decide what gets built. The machine does the rest.

01

Describe

Write the idea in plain words. The planner says what it understood and asks before it plans.

02

Plan

Milestones in order, each saying what you can do when it is done. Stories for one milestone at a time.

03

Approve

One decision approves a milestone. Nothing is built that you did not say yes to.

04

Build

A developer writes it in a sandbox, a reviewer that cannot write checks it, CI tests it, then it merges.

Inside a story

Eight steps, two of them yours.

Every story takes the same path. The machine does six steps. You approve the plan and decide when a milestone is done.

01 machine

Plan

The planner writes the stories for one milestone against the code as it is. A second planner call reviews them.

02 you

Approve

One decision approves the whole milestone. Nothing is built that you did not say yes to.

03 machine

Develop

Claude Code writes the story in a sandbox with no network, on a local model or on Claude.

04 machine

Test

The app's own tests must pass before anyone looks at the code.

05 machine

Review

An independent reviewer that cannot write reads the code and the screenshots, and sends findings back.

06 machine

CI

The pull request waits for every required check on GitHub.

07 machine

Merge

Supervisor merges and marks the story Done. The next one starts.

08 you

Check

The finished milestone is tried in the running app. You read the report and decide.

Updates itself
After a merge to Smidu, Supervisor installs its new version when the queue is still, goes back if it fails, and tries stopped work again.
One queue for every app
One Supervisor builds all apps. The local model takes one story at a time; Claude stories run beside it.

Principles

Built to be trusted, not just to be fast.

Nothing is built without your yes

Every story starts as a Draft. Only the owner sets it Ready, one milestone at a time.

Every stop says why

When the work cannot go on, it stops with a reason and what to do, instead of guessing.

Reports say what was not verified

A milestone report marks every line verified or not verified, and says what it saw.

Private stays private

This page is built from an allowlist of public fields on the private machine, checked, and only then published.
